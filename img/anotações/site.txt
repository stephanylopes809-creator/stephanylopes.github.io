# ?? ?? ESTRUTURA DO SEU PROJETO

Crie uma pasta com esse nome:

```plaintext
meu-site/
```

E dentro dela, monte exatamente assim:

```plaintext
meu-site/
¦
+-- index.html
+-- style.css
+-- script.js (opcional)
¦
+-- img/
¦   +-- foto.jpg
¦
+-- assets/ (opcional)
```
